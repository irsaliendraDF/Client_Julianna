# Julianna Systems — Hidden Cost Diagnostic

A free 3-step landing page that surfaces the real cost of turnover and burnout for leaders in legacy and emerging industries (industrial, manufacturing, construction, supply chain, energy, engineering, tech, healthcare, recruitment).

Built as the Tier 0 free asset in the Julianna Systems funnel: free diagnostic → workshop → Burnout Audit.

## Live URL

To be wired up via Vercel.

## Files

- `index.html` — production landing page. Single static file, deployable to Vercel with no build step.
- `talent_turnover_cost_calculator.html` — V1 reference draft (basic turnover calculator).
- `talent_turnover_full_calculator.html` — V2 reference draft (adds burnout signals + generational panel).
- `talent_turnover_calculator_v3.html` — V3 reference draft (adds the "what if" savings simulator).

## Stack

- Vanilla HTML, CSS, JavaScript. No build, no framework, no package manager.
- Google Fonts: Space Grotesk (headers), IBM Plex Mono (body), Fraunces (italic accents).
- Inline SVG icons, Lucide-style.
- Single file, around 85 KB on disk.

## Deploy on Vercel

1. Connect this repo to Vercel.
2. Vercel auto-detects `index.html` at the root. No build configuration needed.
3. Pushes to `main` deploy automatically.
